# مسار — النظريات المفسرة للنمو الإنساني

موقع ثابت للمذاكرة الذاتية للفصل السابع من «سيكولوجية النمو الإنساني» (ص ٢٢٥–٢٦٦).
HTML و CSS و JavaScript فقط، بلا إطار عمل ولا خطوة بناء ولا خادم ولا تسجيل دخول.

## التشغيل

- افتح `index.html` مباشرة في المتصفح، أو
- استضف المجلد كما هو على أي خادم ثابت (GitHub Pages، Netlify، …)، أو محليًا:
  `python3 -m http.server` ثم افتح `http://localhost:8000`.

## بنية الملفات

| المسار | المحتوى |
|---|---|
| `index.html` | الهيكل فقط: الشريط العلوي، العمود الجانبي، `<main id="main">`، شريط التبويب للجوال، حوارا عارض الصفحات والوحدات |
| `css/masar.css` | الهوية البصرية (ورق عاجي، كحلي، نحاسي)، الوضع الليلي، نقاط الانكسار، الطباعة |
| `js/app.js` | التوجيه بالروابط (`#course`، `#unit-u1-practice`…)، التدريب، المراجعة المتباعدة، المحاكاة، الخرائط، المقارنات، عارض الصفحات |
| `data/course.js` | بيانات المقرر: الوحدات والمحاور والعقد والمقارنات والأعلام ومفاتيح الاسترجاع |
| `data/questions.js` | بنك الأسئلة و`bankVersion` |
| `data/notes.js` | ملاحظات التدقيق على نص المذكرة، والاستشهادات الواردة في المتن |
| `pages/p-<رقم الصفحة المطبوعة>.webp` | صورة كل صفحة مطبوعة (مثل `p-229.webp`)، يفتحها زر «راجع الأصل» |
| `fonts/` | خطّا Amiri و IBM Plex Sans Arabic مستضافان محليًا (woff2)، مع Google Fonts بديلًا |
| `tools/validate.js` | فحص البيانات قبل النشر |

أسماء ملفات الصور تتبع **رقم الصفحة المطبوع** لا ترتيبها في ملف PDF، لأن كل أزرار المصدر تشير إلى الرقم المطبوع.
ص ٢٢٦ غير موجودة في الملف المرفق؛ ولهذا هي مدرجة في `course.missingPages`، ويتخطاها العارض.

## إضافة محتوى أو تعديله

كل المحتوى في `data/*.js`، ولا يُكتب أي نص تعليمي في `app.js`.

### عقدة في خريطة مفاهيم

داخل `topics[].nodes` في `data/course.js`:

```js
['المصطلح', 'الشرح منقولًا من المذكرة بين «»', 229]          // صفحة واحدة
['المصطلح', 'الشرح', 236, 235]                               // صفحتان
```

لكل محور `title` و`from` و`to` و`intro` و`key` (مفتاح استرجاع من سطر واحد، مبني على المذكرة وحدها).

### سؤال

في `data/questions.js`:

```js
{ id: 'u1-q09', unit: 'u1', topic: 2, cat: 'distinctions', page: 231,
  q: 'نص السؤال',
  options: ['أ', 'ب', 'ج', 'د'],   // أربعة بالضبط
  correct: 2,                      // فهرس يبدأ من ٠
  near: 0,                         // أقرب مُشتِّت، ولا يساوي correct
  why: 'لماذا الإجابة صحيحة، مع الصفحة',
  nearWhy: 'لماذا أقرب مُشتِّت خطأ، مع الصفحة' }
```

التصنيفات المتاحة: `definitions`، `concepts`، `distinctions`، `figures`، `applications`.

**ارفع `MASAR.bankVersion`** كلما غيّرت محتوى الخيارات أو ترتيبها؛ فيُعاد ضبط الإجابات المحفوظة لهذا الكتاب وحده.

### جدول مقارنة

داخل `comparisons` في الوحدة: `id` و`title` و`ref` و`page` و`topic` (اختياري، لربط زر «تدرّب على أسئلة هذه المقارنة») و`desc` و`headings` و`rows` و`note`.
كل ما هو صياغة من إعداد الموقع لا من نص المذكرة يُذكر صراحةً في `note`.

### قواعد المحتوى

1. المصدر الوحيد هو المذكرة. ما لم يرد فيها لا يرد في الموقع.
2. كل عقدة وسؤال ومقارنة وعَلَم يحمل رقم صفحة مطبوعة.
3. يُنقل التعريف بنصه بين «»، ولا يُعاد صوغه.
4. الخطأ الطباعي في المذكرة يُنقل كما هو، ويُسجَّل في `MASAR.audit` في `data/notes.js`.
5. الأرقام المعروضة للمستخدم بالأرقام العربية المشرقية (٠١٢٣…). `app.js` يحوّل أي رقم غربي عند العرض، لكن اكتب النصوص العربية بالأرقام المشرقية من الأصل.
6. لا رموز تعبيرية، ولا تدرجات لونية، ولا عناصر «تحفيز» مثل النقاط أو الشعلات.

## الفحص قبل النشر

```sh
node tools/validate.js
```

يتحقق من: نطاقات الصفحات ووجود صورها، وأن لكل سؤال أربعة خيارات وإجابة واحدة و`near` مختلفًا عن `correct` و`why` و`nearWhy` وصفحة صالحة، وتوزيع مواضع الإجابات الصحيحة، وألا يكون الخيار الصحيح أطول بوضوح، وغياب الرموز التعبيرية، والأرقام الغربية في النصوص العربية (يُستثنى الاستشهاد اللاتيني كما طُبع). يخرج برمز ١ إذا وجد خطأ.

## حفظ التقدم

يُحفظ في `localStorage` تحت مفاتيح تبدأ بـ `masar:nomow-ch7:`، وإن كان التخزين معطّلًا يعمل الموقع من الذاكرة ويُنبَّه المستخدم في صفحة «عن هذا الكتاب».
الوضع الليلي يُحفظ في `masar:theme`، ويُطبَّق قبل أول رسم.

- **الإنجاز**: الأسئلة المُجاب عنها مرة على الأقل.
- **الدقة**: من آخر إجابة لكل سؤال.
- **وحدة متقنة**: كل أسئلتها مُجابة، والدقة ٨٠٪ فأكثر.
- **المراجعة المتباعدة**: خمسة صناديق بفواصل ١ و٢ و٤ و٨ و١٦ يومًا.
- **محاولات الاختبار**: سجل مستقل لا يغيّر إحصاءات التدريب.

## حالة المحتوى

الحالة «مدقق»: قوبل المحتوى بصور صفحات المذكرة. الاعتماد النهائي («معتمد») متروك لمراجعة صاحب المقرر.
الأسئلة والتعليلات صياغات تعليمية مقترحة، وليست أسئلة رسمية ولا توقعات للاختبار.
